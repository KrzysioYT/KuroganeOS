# KuroganeOS 5.0 GUI Icon Pack

Pakiet przygotowany na podstawie koncepcyjnego arkusza ikon KuroganeOS 5.0.

## Zawartość
- 150 ikon
- kategorie: applications, folders, file_types, drives, status, actions, navigation, cursors, widgets, special, boot
- PNG RGBA z przezroczystością
- rozmiary: 64x64, 128x128, 256x256
- `manifest.json` z mapą nazw i ścieżek
- `SOURCE_SHEET.png` — oryginalny arkusz koncepcyjny

## Zalecenie do GUI
Najlepiej używać 64x64 i 128x128. Wariant 256x256 jest skalowany z arkusza i służy głównie do wygodnego prototypowania.

## Ważne
Ikony zostały automatycznie wycięte i odseparowane od tła z wygenerowanego arkusza koncepcyjnego, dlatego pojedyncze ikony mogą wymagać drobnego ręcznego retuszu przed finalnym wydaniem systemu.
