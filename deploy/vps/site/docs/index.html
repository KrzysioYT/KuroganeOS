OFFICIAL DEVELOPMENT DOCUMENTATION

KuroganeOS 5.0

Niezależny system x86-64 uruchamiany przez UEFI. Własny kernel, procesy Ring-3, pulpit Forged Steel, storage, sieć i natywne aplikacje.

Status: dokumentacja opisuje faktycznie zaimplementowany runtime. Funkcje rozwojowe są oznaczane wprost i nie są prezentowane jako gotowe.

Architektura

FirmwareUEFI + BOOTX64.EFI
Kernelx86-64, VMM, scheduler, syscalle
UserspaceELF64, Ring-3, IPC, VFS
DesktopForged Surface + WindowManager

System nie jest dystrybucją innego systemu operacyjnego. Obraz startuje własny kernel i własne aplikacje bez warstwy Linux/Windows/macOS w środku.

Sieć i TLS

Stos obejmuje sterowniki E1000, PCnet i VirtIO-net oraz ARP, IPv4, ICMP, UDP, DHCP, DNS, TCP, HTTP i TLS 1.2. Walidacja certyfikatu, nazwy hosta i czasu RTC pozostaje fail-closed.

Oficjalny build używa przypiętego w repozytorium zestawu Mozilla CA. Nie importuje zaufania z systemu kompilującego.

Anvil Package Manager

Repozytorium https://repo.kuroganeos.dev/index.kuro publikuje katalog pakietów. Anvil pobiera metadane, rozwiązuje zależności, weryfikuje SHA-256 i zapisuje pakiety przez VFS.

Kwalifikacja obrazu

Pipeline wydania buduje ISO i IMG od zera, sprawdza strukturę nośników, uruchamia obraz przez OVMF oraz kwalifikuje osobne ścieżki E1000, PCnet i VirtIO-net. Testy runtime obejmują start kernela, PID 1, Ring-3, pulpit, VFS i sieć.

ISO20 kontroli struktury
OVMFboot + framebuffer
NetworkDHCP, DNS, TCP, HTTP
TrustMozilla CA, fail-closed TLS

Publiczne HTTPS dla domen KuroganeOS wymaga aktywnych rekordów DNS. Brak DNS jest raportowany jako błąd połączenia; aplikacje nie zastępują go fałszywym wynikiem.

Uruchamianie obrazu

  1. 01
    Pobierz ISO lub IMG

    Użyj oficjalnego katalogu i sprawdź SHA-256.

  2. 02
    Włącz UEFI/OVMF

    Dla QEMU użyj maszyny q35. Secure Boot pozostaje wyłączony.

  3. 03
    Uruchom na pustym dysku testowym

    To wydanie rozwojowe; nie kieruj instalatora na dysk z ważnymi danymi.

qemu-system-x86_64 -machine q35 -m 2048 \ -drive if=pflash,format=raw,readonly=on,file=OVMF_CODE.fd \ -drive format=raw,file=KuroganeOS-3.3.3-dev-linux-qemu.img
