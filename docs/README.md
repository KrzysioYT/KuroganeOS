# Dokumentacja KuroganeOS

Runtime **7.0.0-dev**, priorytet **Flux Modern 8.0**, cel **15.0.0 stable**.
[Stan i dowody](../DEVELOPMENT_STATE.md) jest jedynym bieżącym podsumowaniem.
[Master roadmap](roadmap/MASTER_ROADMAP_15.md) określa numerację;
[kontrakt Flux 8](roadmap/FLUX8_MODERN_COMPLETION.md) określa ukończenie pulpitu.
Dokument techniczny opisuje interfejs lub implementację, nie gwarancję kwalifikacji.

## Utrzymanie dokumentacji

Zmiana kodu wymaga aktualizacji odpowiedniej instrukcji i ograniczeń.
Dowód zawiera SHA, profil, run/log, wynik oraz hash media, jeżeli dotyczy obrazu.
Nie nadpisujemy dawnych FAIL/PASS; dopisujemy wynik nowej rewizji.
Nie nazywamy prototypu stable, nie przenosimy wyniku QEMU na VirtualBox ani PC.
Stare plany i audyty pozostają zapisami historii, a nie listą bieżących braków.
