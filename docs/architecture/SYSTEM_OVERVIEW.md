# System overview

Bieżący opis warstw: [current/ARCHITECTURE.md](../current/ARCHITECTURE.md).
Szczegóły startu: [BOOT_PROCESS.md](../BOOT_PROCESS.md).
Status implementacji i testów: [DEVELOPMENT_STATE.md](../../DEVELOPMENT_STATE.md).

System pozostaje natywnym x86-64 UEFI. Wersja runtime `7.0.0-dev`, aktywny
priorytet Flux Modern 8.0, docelowe wydanie 15.0.0 stable. Historyczne
ograniczenia 3.3/3.4 nie opisują bieżącej obsługi SMP, NVMe, usług ani audio.
