# KuroganeOS 2.2.0 — Desktop Developer Preview

Data: 2026-08-16

## Cel

2.2 naprawia rozjazd, który powstał podczas przejścia z kernel shella do Ring 3:
fundament systemu był już znacznie bardziej zaawansowany, ale domyślna powłoka
użytkownika została zredukowana do kilku komend, a desktop zachował wygląd
prototypowego klasycznego WindowManagera.

## Najważniejsze zmiany

### Kurogane Flux

- nowa identyfikacja wizualna niezależna od Windows/macOS/Linux desktopów;
- signal spine, status nodes i asymetryczne powierzchnie;
- pulse ribbon zamiast klasycznego taskbara/docka;
- segmentowe wskaźniki postępu;
- przeprojektowane ramki/controls bez zmiany działającej mechaniki okien.

### Flux Console

- nowy banner i prompt `KRG::<cwd> >`;
- historia i status ostatniej komendy;
- logiczny CWD;
- `run <name|path>`;
- `open`, `gui`, `jobs`, `wait`;
- `cat/read`, `which`, `apps`;
- `calc` z kontrolą overflow;
- `sleep`, `yield`, `true`, `false`;
- skróty diagnostyczne do userspace System Monitor;
- rozpoznawanie legacy commands, których capability ABI jeszcze nie posiada.

### Documentation repair

Zaktualizowano dokumenty, które nadal twierdziły, że aktualny KuroganeOS 1.0
nie ma Ring 3, procesów, syscalli, myszy, persistent storage lub WindowManagera.

## Nie zmieniono

Patch celowo nie przebudowuje bootloadera, installera, AHCI/GPT/FAT32 ani
backendu macOS 2.1.1. Te elementy są fundamentem, a nie częścią wizualnego
refaktoru 2.2.

## Weryfikacja

Kod shella i nowej warstwy UI przeszedł lokalny syntax/Werror check. Pełny
repozytoryjny build oraz boot QEMU/VirtualBox powinny zostać wykonane po
pobraniu commita i nie są zastępowane samym statycznym sprawdzeniem.
