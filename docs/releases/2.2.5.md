# KuroganeOS 2.2.5 — macOS ISO & build repair

Data: 2026-08-16

## Cel

2.2.5 jest poprawką build/release do Desktop Developer Preview 2.2.0. Naprawia
regresję kompilacji GUI Terminala oraz kończy natywny workflow macOS o budowę
instalowalnego ISO bez PowerShella i bez ręcznej konwersji obrazu `.img`.

## Naprawione

- `userspace/gui/terminal/main.c` nie kończy już builda błędem
  `version.h: No such file or directory`;
- SDK builder na Unix/macOS jawnie widzi katalog `common/`;
- include wersji w Flux Terminalu jest niezależny od working directory;
- `setup-macos.sh` sprawdza również `xorriso`.

## Natywne ISO macOS

Nowy `scripts/build-installer-macos.sh`:

1. buduje kernel, userspace, SDK i `BOOTX64.EFI` natywnym backendem macOS;
2. generuje `build/install.pkg`;
3. tworzy staging installera;
4. tworzy osobny 64 MiB FAT32 EFI System Partition przez dosfstools/mtools;
5. umieszcza na ESP `BOOTX64.EFI`, kernel i `install.pkg`;
6. generuje UEFI/El Torito ISO przez `xorriso`;
7. publikuje:

```text
dist/KuroganeOS-2.2.5-x86_64.iso
dist/SHA256SUMS.txt
kurogane.iso
```

Nie ma etapu IMG -> ISO.

## Komendy

Development IMG:

```bash
./scripts/build-macos.sh --configuration debug --rebuild
```

Development IMG + ISO:

```bash
./scripts/build-macos.sh --configuration release --rebuild --iso
```

Tylko installer ISO:

```bash
./scripts/build-installer-macos.sh --configuration release --rebuild
```

Kompatybilna stara komenda:

```bash
./scripts/build-iso.sh release
```

## Zakres

2.2.5 nie zmienia ABI Ring-3, storage runtime, installera target-side ani języka
wizualnego Kurogane Flux. Jest to patch build/release i naprawa regresji 2.2.0.
