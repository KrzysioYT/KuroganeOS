# KuroganeOS 2.3.0 — Desktop Boot Repair

KuroganeOS 2.3.0 naprawia główną regresję Desktop Developer Preview: system
posiadał WindowManager, publiczne UI ABI i aplikacje `/gui/*`, ale normalna
sesja userspace kończyła się uruchomieniem tekstowego `/apps/shell`.

## Co zmieniono

### Flux desktop session

Dodano kernelowy host sesji `flux-session`, uruchamiany automatycznie przy
inicjalizacji normalnego userspace console. Sesja:

- inicjalizuje istniejący WindowManager;
- przejmuje routing input przez `applications`;
- renderuje WindowManager w kernel loop;
- okresowo odświeża framebuffer, aby usunąć boot-logi z powierzchni GUI;
- nie uruchamia się w Safe Mode.

Marker poprawnego startu:

```text
[TEST] desktop_session: PASS
```

### PID 1 jako supervisor desktopu

`/system/init` nie uruchamia już domyślnie `/apps/shell`. PID1 startuje:

```text
/gui/terminal
/gui/files
/gui/sysmon
/gui/settings
/gui/about
```

Po udanym starcie raportuje:

```text
[TEST] desktop_userspace_apps: PASS
[TEST] userspace_desktop_session: PASS
```

Zakończone aplikacje desktopowe są restartowane. Jeżeli podczas początkowego
probe większość GUI kończy się natychmiast, PID1 przechodzi do tekstowego
`/apps/shell` jako awaryjnego fallbacku.

### Session configuration

`rootfs/etc/system.cfg` ma od 2.3:

```text
BOOT_MODE=desktop
```

Safe Mode pozostaje tekstowym środowiskiem ratunkowym.

## Ważne ograniczenie 2.3

Bootloader UEFI nadal zawiera historyczny prompt z Desktop Alpha/console.
2.3 nie opiera już normalnej sesji GUI na ręcznym `D`: Flux session startuje
po wejściu kernela w normalny userspace path. Pełne usunięcie legacy chrome i
starych nazw boot/UI jest częścią 2.4 Flux Window Core.

WindowManager wciąż ma część klasycznych elementów Desktop Alpha. 2.3 naprawia
**uruchamianie i lifecycle GUI**, a 2.4 przebuduje wygląd WindowManagera.

## Build macOS

Development IMG:

```bash
./scripts/build-macos.sh --configuration debug --rebuild
```

IMG + ISO:

```bash
./scripts/build-macos.sh --configuration release --rebuild --iso
```

Wyniki:

```text
dist/KuroganeOS-2.3.0-macos-qemu.img
dist/KuroganeOS-2.3.0-x86_64.iso
```

Test GUI:

```bash
./scripts/run-qemu-macos.sh \
  --image ./dist/KuroganeOS-2.3.0-macos-qemu.img \
  --display
```
