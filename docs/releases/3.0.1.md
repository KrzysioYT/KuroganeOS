# KuroganeOS 3.0.1 — Desktop Stabilization

KuroganeOS 3.0.1 stabilizuje pierwszy release Kurogane Desktop po realnych
testach QEMU. Patch nie dokłada kolejnego skinu ani nowej warstwy preview —
naprawia zachowanie istniejącego Flux Window Core.

## Najważniejsza naprawa: ghosting

2.4.1 wprowadziło `content dirty`, które dla `KU_SYS_UI_PRESENT` przerysowywało
warstwy na starym framebufferze bez odtworzenia tła. Dzięki temu zniknęło
wcześniejsze agresywne miganie, ale zmieniający się tekst i okna zostawiały
stare piksele pod nową klatką.

3.0.1 wraca do deterministycznego modelu immediate-mode:

```text
state/content change
 -> mark full dirty
 -> hide software cursor
 -> draw complete Flux desktop
 -> draw windows in z-order
 -> draw Pulse Ribbon
 -> restore software cursor
```

Nie ma okresowego timer-driven repaintu. Pełny repaint występuje tylko po realnej
zmianie stanu lub treści, więc usunięty zostaje ghosting bez przywracania pętli
10 Hz, która powodowała miganie w 2.4.0.

## Interactive resize

Bottom-right Flux grip jest teraz aktywny:

- kliknięcie gripu rozpoczyna resize;
- przeciąganie lewym przyciskiem zmienia width/height;
- rozmiar jest ograniczony do Flux work area;
- minimalny rozmiar okna to 220x140;
- maximized windows nie są resize'owane przez grip;
- release lewego przycisku kończy operację;
- restore bounds są aktualizowane podczas resize.

## Model sesji 3.0

Pozostaje model z 3.0.0:

```text
/system/init
 -> /gui/launcher (Flux Home)
 -> aplikacje otwierane na żądanie
```

Normalny boot nie uruchamia już pięciu nakładających się aplikacji. PID1
nadzoruje root sesji, a zwykłe aplikacje są dziećmi Launchera.

## Build macOS

```bash
./scripts/build-macos.sh --configuration debug --rebuild
```

Development image:

```text
dist/KuroganeOS-3.0.1-macos-qemu.img
```

Uruchomienie:

```bash
qemu-system-x86_64 \
  -machine q35,accel=tcg \
  -cpu max \
  -m 768 \
  -vga std \
  -drive if=pflash,format=raw,unit=0,readonly=on,file="$(brew --prefix qemu)/share/qemu/edk2-x86_64-code.fd" \
  -drive if=pflash,format=raw,unit=1,file=/tmp/kurogane-vars.fd \
  -drive if=none,id=kurogane_system,format=raw,file="./dist/KuroganeOS-3.0.1-macos-qemu.img",cache=writeback \
  -device ide-hd,drive=kurogane_system,bus=ide.0,bootindex=1 \
  -display cocoa \
  -serial stdio \
  -net none \
  -no-reboot \
  -no-shutdown
```

Pełny runtime PASS nadal wymaga testu na rzeczywistym Macu/QEMU. Commit nie jest
sam w sobie dowodem braku wszystkich artefaktów renderera.
