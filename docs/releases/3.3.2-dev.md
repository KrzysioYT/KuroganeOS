# KuroganeOS 3.3.2-dev — Home Session Safety

Status: **DEV BETA**

3.3.2-dev naprawia krytyczny błąd lifecycle Red Flux Home. W 3.3.1 Home było
jednocześnie widocznym oknem oraz rootem drzewa procesów sesji. Zamknięcie
zwykłego okna Home kończyło proces root i powodowało niezamierzony logout.

## Zmiany

- Home pozostaje trwałym rootem sesji po Login;
- surface Home startuje zminimalizowany, więc użytkownik dostaje czysty pulpit;
- przypięty `HOME` w Docku jest wyraźnym przyciskiem;
- pulpit ma własny skrót/ikonę `HOME`;
- oba punkty wejścia otwierają albo przywracają ten sam Home;
- `X` i `Alt+F4` na Home tylko chowają/minimalizują jego surface;
- Home nie jest już duplikowane jako zwykły dynamiczny task Docka;
- pozostałe piny Docka nadal uruchamiają aplikacje przez żywy proces Home;
- logout nie jest już skutkiem zamknięcia okna; musi być osobną akcją sesji.

## Oczekiwany flow

```text
Login
  -> Red Flux Desktop
       -> desktop HOME shortcut
       -> Dock HOME button
       -> Terminal / Files / Monitor / Settings / About
```

Po kliknięciu Home:

```text
HOME hidden -> restore/focus
HOME visible -> focus
HOME X/Alt+F4 -> minimize/hide, session remains alive
```

## Acceptance

1. Login -> desktop bez automatycznie otwartego Home.
2. Na pulpicie widać ikonę `HOME`.
3. W Docku widać przycisk `HOME`.
4. Kliknięcie obu otwiera Home.
5. Zamknięcie Home przez `X` nie wraca do Login.
6. `Alt+F4` na Home nie wraca do Login.
7. Po schowaniu Home można z Docka uruchomić Terminal/Files/Monitor/Settings/About.
8. Ponowne kliknięcie `HOME` przywraca tę samą powierzchnię.
