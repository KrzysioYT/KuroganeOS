# KuroganeOS 3.3.4-dev

Version: `3.3.4-dev`
Channel: `DEV`
Release status: `IN PROGRESS / QUALIFICATION`
Date: not released
Baseline: `3.3.3-dev` at `17bd55091c63544b9585840192f0eb288e9cffff`

## Summary

3.3.4-dev is the VirtualBox qualification release. It does not redesign Red Flux and it does not introduce a fake compatibility claim. Its purpose is to prove the existing native UEFI/installer/userspace stack across the complete VirtualBox flow and fix regressions exposed by that qualification.

## Kernel changes

Pending qualification fixes only. No release-wide kernel change is claimed yet.

## Driver changes

The candidate uses a real VirtualBox-compatible storage/network profile. SATA/IntelAHCI is mandatory for install qualification. Network driver work is inherited from 3.3.3-dev and remains subject to regression tests.

## Userspace changes

Qualification must prove the real live-session transition:

`ISO -> Try -> Login -> Red Flux Desktop`

The test must observe the guest's actual serial markers emitted by the live Login and launcher/session code.

## Security changes

No new secure-password claim. `FNV1A64-DEV` remains a known development-only credential verifier and is not a production KDF.

## Networking changes

No new protocol-completeness claim. Existing IPv4/DHCP/DNS/TCP work remains DEV and the active TLS transport work remains unqualified until its real handshake gates pass in the appropriate release.

## Graphics changes

No Direct3D or GPU-acceleration claim. The qualification target is the existing software Red Flux desktop path.

## Filesystem changes

The VirtualBox install gate must prove installation to a SATA VDI, ISO detach, boot from installed media and persistent FAT32 root mount.

## Application changes

No new application feature gate. The desktop launcher is used as a real userspace readiness marker.

## ABI changes

None planned for this release.

## Breaking changes

None planned.

## Known limitations

- Oracle VirtualBox runtime acceptance has not yet been recorded for this candidate.
- NVMe, production xHCI/USB coverage, SMP and hardware GPU acceleration are outside 3.3.4 scope and remain unqualified.
- TLS is not declared complete by this release.
- Real hardware support remains narrower than VM support.
