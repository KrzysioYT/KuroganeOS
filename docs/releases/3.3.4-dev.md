# Historical Red Flux compatibility workstream — 3.3.4 label

> **Historical classification:** `3.3.4-dev` was an internal Red Flux VirtualBox/installer compatibility workstream label. It is **not a formal KuroganeOS product release, next version or release gate**. Relevant implementation belongs to formal milestone **3.3.3-dev — Red Flux**.

- Historical label: `3.3.4-dev`
- Formal milestone: `3.3.3-dev — Red Flux`
- Role: virtual-platform qualification tooling / compatibility work
- Baseline at workstream start: `17bd55091c63544b9585840192f0eb288e9cffff`

## Work performed

The workstream created and hardened tooling intended to exercise real Oracle VirtualBox flows including:

`ISO -> Try -> Login -> Red Flux Desktop`

and install-to-VDI, ISO detach, reboot and persistent-root checks. The harness uses real guest serial markers and does not fabricate VirtualBox PASS results.

Installer reliability, networking, TLS and userspace work later continued in other internal Red Flux branches and is consolidated into the formal `3.3.3-dev` milestone record.

## Current methodology

Oracle VirtualBox host acceptance is **OPTIONAL / EXTERNAL VALIDATION**.

It is not:
- part of formal version percentage calculations;
- a Definition-of-Done requirement;
- a blocker for Red Flux qualification;
- a blocker for progression to `3.4.0-dev — System Services`.

If a suitable Oracle VirtualBox host is available, the existing harness can still provide useful extra compatibility evidence. Until such a run is actually executed, no VirtualBox PASS is claimed.

## Verified automated evidence

The Red Flux milestone has separate completed host/kernel/ABI/SDK/media/FAT32/VFS/OVMF/QEMU/network/TLS qualification evidence recorded in `docs/releases/3.3.3-dev.md` and `docs/roadmap/CURRENT_RELEASE.md`.

## Security and capability boundaries

- `FNV1A64-DEV` remains a development-only credential verifier until Iron Shield replaces it.
- Hardware GPU acceleration, SMP, NVMe parity and broader real-hardware coverage are later formal milestone scope.
- No Direct3D/GPU support is inferred from this compatibility workstream.

## Result

This document is retained only as historical engineering context. There is no formal `3.3.4-dev` release to close or tag. The formal sequence is:

`3.3.3-dev — Red Flux -> 3.4.0-dev — System Services`.
