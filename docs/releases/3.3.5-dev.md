# KuroganeOS 3.3.5-dev

Version: `3.3.5-dev`

Channel: `DEV`

Release status: `IN DEVELOPMENT / NOT RELEASED`

Date: `2026-08-29`

## Summary

3.3.5-dev hardens installer/account persistence while the preceding 3.3.4-dev Oracle VirtualBox release gate remains pending. This branch is stacked development and does not imply that 3.3.4-dev has been released.

## Kernel changes

- Reuses the recoverable installer state-file transaction path introduced during 3.3.4 qualification.
- Keeps FAT32-backed profile and locale persistence on explicit sync boundaries.

## Driver changes

- No new driver feature is claimed by this release branch.

## Userspace changes

- Installer and Login share one explicit development credential verifier instead of maintaining divergent copies of the password hashing logic.
- Installed account profile parsing is fail-closed.
- Malformed or incomplete `/etc/user.cfg` cannot silently become a passwordless account.
- Profile parser validates username, password-required state, hash encoding, hash scheme and supported locale.

## Security changes

- Fixed an authentication fail-open condition caused by accepting the existence of `/etc/user.cfg` as sufficient proof of a valid installed profile.
- Bad passwords are explicitly rejected by regression coverage.
- `FNV1A64-DEV` remains a DEVELOPMENT-ONLY credential scheme. It is not described as secure and remains scheduled for cryptographic replacement during Iron Shield development.

## Networking changes

No release-specific networking feature.

## Graphics changes

No release-specific graphics feature.

## Filesystem changes

- Profile/locale persistence tests exercise production FAT32 and recoverable state replacement.
- Persistence regression recreates the filesystem object after `sync` before reading the installed profile again.

## Application changes

- Login accepts a valid persisted profile and valid password.
- Login rejects an invalid password and malformed profile.

## ABI changes

No public ABI break is intentionally introduced.

## Breaking changes

None currently declared.

## Known limitations

- `FNV1A64-DEV` is not a secure password KDF.
- Real Oracle VirtualBox installation/profile acceptance remains pending through the still-open 3.3.4 release gate.
- This document describes an active development branch, not a released artifact.
