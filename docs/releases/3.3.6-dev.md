# KuroganeOS 3.3.6-dev

Version: `3.3.6-dev`

Channel: `DEV`

Date: `2026-08-29`

## Summary

3.3.6-dev focuses on transport reliability and honest TCP connection teardown. The branch is stacked on unfinished earlier release work and is not a released version.

## Kernel changes

- TCP client close handling is bounded and state-aware instead of clearing the client object after one FIN attempt.
- Teardown processes peer responses and uses an explicit reset/abort fallback when graceful closure cannot be completed.

## Driver changes

- Existing E1000/PCnet/VirtIO networking remains the driver baseline; no new driver support is claimed by this release note.

## Userspace changes

No new public userspace socket ABI is claimed in 3.3.6-dev.

## Security changes

- Removed a fake-success behavior where `close()` could report success after FIN transmission failed locally.
- Failure paths preserve explicit transport status rather than pretending a graceful shutdown occurred.

## Networking changes

- FIN transmission is retried through a bounded graceful-close path.
- CLOSE-WAIT/peer-close processing is covered by regression tests.
- Abort fallback emits a real reset path rather than silently discarding connection state.
- Existing TCP regression coverage remains required alongside the new close regression.

## Graphics changes

No release-specific graphics change.

## Filesystem changes

No release-specific filesystem change.

## Application changes

TLS/session cleanup benefits from the corrected TCP close path because TLS session teardown uses the production TCP client.

## ABI changes

No intentional public ABI break.

## Breaking changes

- Public asynchronous userspace networking is a later roadmap item.
- Release qualification is not complete.
