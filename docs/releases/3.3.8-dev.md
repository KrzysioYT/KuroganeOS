# KuroganeOS 3.3.8-dev

Version: `3.3.8-dev`

Channel: `DEV`

## Summary

3.3.8-dev audits and hardens userspace I/O ownership and process resource accounting. This is stacked development while earlier release gates remain open.

## Kernel changes

- `process::Stat.handle_count` is now fed by the real runtime file-handle table instead of remaining a permanently zero placeholder.
- Process accounting exposes a dedicated handle-count update path used by the runtime lifecycle.

## Driver changes

No new hardware driver support is claimed by this release branch.

## Userspace changes

- Runtime synchronizes open file-handle ownership into process statistics after successful open and close operations.
- Runtime cleanup closes active file handles, clears slots and publishes the resulting zero count before process resource teardown.
- Existing runtime cleanup paths also cover UI/audio/address-space resources; broader lifecycle qualification is still pending.

## Security changes

- Removes fake process telemetry for open file handles.
- Resource accounting now reflects actual owned runtime objects, improving the basis for deterministic cleanup and later capability/security enforcement.

## Networking changes

Userspace networking remains foundation work; no completed public network userspace ABI is claimed here.

## Graphics changes

No new graphics backend feature is claimed.

## Filesystem changes

- File-handle ownership is tracked against actual runtime file slots.
- Open/close/cleanup transitions update process-visible accounting.

## Application changes

Process/system-monitor consumers can receive real handle counts instead of hardcoded zero once they consume this statistic.

## ABI changes

Internal process accounting gains a handle-count update path. No stable external ABI break is declared.

## Breaking changes

None currently declared.

## Known limitations

- Full read/write/seek/stat/directory userspace API closeout is not yet qualified as a release.
- Exit/fault/forced-termination resource lifetime needs dedicated end-to-end regression evidence.
- Async userspace audio/networking are still later work.
