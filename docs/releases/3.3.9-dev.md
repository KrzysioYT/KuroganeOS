# KuroganeOS 3.3.9-dev

- **Version:** 3.3.9-dev
- **Channel:** DEV
- **Release status:** IN DEVELOPMENT / FEATURE FREEZE
- **Date:** 2026-08-29
- **Generation:** Red Flux

## Summary

3.3.9-dev is the Red Flux closeout development state. It combines the verified
3.3.7 TLS foundation and 3.3.8 userspace I/O/resource-ownership work and does
not introduce a new major subsystem. The formal sequential release gate remains
3.3.4-dev because real Oracle VirtualBox host acceptance has not been executed.
This document records stacked development evidence, not a released/tagged 3.3.9.

## Kernel changes

- Combined hardened RTC/TLS with userspace process handle accounting.
- Full host regression executes IPC channel, IPC event and shared-memory
  ownership tests instead of leaving them outside the normal closeout suite.

## Driver changes

No new major driver feature is introduced by feature freeze. E1000, PCnet and
VirtIO-net virtual NIC paths remain covered by the QEMU NAT matrix.

## Userspace changes

- Retains real file-handle ownership telemetry from 3.3.8.
- Runtime cleanup closes active root-volume handles before publishing final
  process handle count.
- IPC/shared-memory/event process-release paths remain part of userspace
  resource lifecycle and are covered by the full host suite.

## Security changes

- TLS certificate validation remains fail-closed.
- Peer X.509 certificate retention is enabled where post-handshake validation
  requires it.
- Certificate expiry/time validation remains enabled; it was not bypassed to
  obtain qualification success.
- `FNV1A64-DEV` remains a known insecure development password verifier and is
  not promoted as a production credential KDF.

## Networking changes

No new network feature is added in 3.3.9. The closeout candidate retains the
real HTTPS/TLS handshake path qualified in 3.3.7 and reruns it after combining
3.3.7 and 3.3.8 work.

## Graphics changes

No major graphics feature is introduced. Red Flux remains software rendered.

## Filesystem changes

No new filesystem feature is introduced. Recoverable installer state
replacement and production FAT32 integration from earlier stacked 3.3.x work
remain present.

## Application changes

No major application feature is introduced by feature freeze.

## ABI changes

No new ABI version is declared by this closeout step.

## Breaking changes

None intentionally introduced.
